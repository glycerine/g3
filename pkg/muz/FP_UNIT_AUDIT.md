# Fixedpoint SMT-LIB command unit audit

Scope: `src/muz/fp/dl_cmds.h` and `dl_cmds.cpp` (source snapshot under `pkg/muz/fp/cppsrc/fp`), inspected 2026-11-03. Both units remain **partial**. This is a command-boundary audit, not a claim that the underlying engines, all parameter consumers, or failure ownership paths are complete.

The live source installers are `src/shell/smtlib_frontend.cpp:78` (executing commands) and `src/api/api_datalog.cpp:364` (`Z3_fixedpoint_from_stream`, collecting). The latter returns collected queries, registers collected relations, adds collected rules/names, then transfers ordinary assertions; it does not transfer the parser context's representation choices or rule bounds. Go equivalents are `pkg/parsers/smt2/commands.go`, `pkg/cmd_context/fixedpoint.go`, `pkg/parsers/smt2/fixedpoint_query_collector.go`, and `pkg/api/api_fixedpoint_object_load_queries.go`. The header's include guard has no runtime branch; its vector owners and two installer declarations map to `FixedpointProgram` and the parser's execution/collection modes. The Go collector owns AST references and releases them on error and scope truncation.

Existing tests demonstrate reachable slices, not all conditional combinations. In particular, backend capabilities and errors remain independently partial, and a green parser test cannot establish complete command exception, cancellation, reset, or resource-refusal fidelity. No source unit or manifest status is promoted by this audit.
