## Source-to-Go mapping and evidence

- Source constructor, priority and disabled no-op: `ScalePlugin` owns manager, rule manager and priority; its caller conditionally registers it. Direct `Transform` always transforms, so the no-op is a pipeline responsibility. Default priority 33039 is a C++ constructor default; the live registration supplies 36030, as does Go.
- Source `operator()` loops through rules, clears per-rule caches, obtains variable count, rewrites positive and negative uninterpreted tails, then interpreted tails and head, appends equality constraints and positive sigma, creates all-false negation flags, preserves the rule symbol and propagates output heads. `scale.go:231` performs these steps. All-false flags reproduce the source, including for originally negated tails; this audit does not assert that scaling negated rules is logically sound. `InheritPredicate` also records origin and metadata for the Go consumer.
- Source `mk_pred` extends each signature with Real sigma, leaves zero, substitutes sigma for one, introduces a fresh Real variable and equality for other numeral arguments, appends sigma and registers each predicate. `scale.go:56` implements these branches and caches old-to-new declarations. `TestScaleAddsHomogeneousPredicateArgumentAndGuards` checks zero/one, arity and guard count; `TestScaleReusedDeclarationInheritsCurrentOutputs` checks reuse, output metadata and origin; `TestRuleName...` auxiliary-symbol coverage exercises the source rule symbol through this transform.
- Source `linearize` memoizes applications; it descends through basic-family operators and arithmetic add/subtract/comparisons, multiplies isolated numerals by sigma, and leaves other applications and non-applications unchanged. `scale.go:150` follows that structure. `TestScaleNestedConstraintAndPredicateNumerals`, `TestScaleResetsCacheBetweenRulesAndClearsNegation` and the base transform tests exercise nested interpreted expressions, multiple numeral equalities, rule-local cache reset and source tail flags.
- Source converter maps each new declaration back to its old declaration, substitutes sigma = 1 into total, entry-free function interpretations, preserves unscaled interpretations and replaces the model. `expandSpacerScaledFunction` implements the substitution, removes derived declarations and registers originals; the surrounding conversion pipeline carries other model entries. `TestSpacerScaleReconstructsOriginalPredicateModel` covers unary and nullary reconstruction, and the PDR/Spacer scale pipeline tests validate models against original clauses. Source's `translate` is explicitly unreachable and needs no generic translation adapter.
- The C++ destructor relies on reference-owned trails and its converter's declaration trail. Go keeps temporary pins, rules and result sets in a retryable plugin-owned cleanup ledger and publishes the declaration map after successful construction. A staged owner test invokes cleanup during an actual native allocation callback, checks refusal, retry and zero-budget disposal; an integer/real construction failure checks that no partial predicate map is published. Registration with the rule manager remains persistent and idempotent. The transformer closes the plugin, and `FreshPredicates` returns a copy.

## Source revision note

The bundled `src/muz/transforms/dl_mk_scale.cpp` checks the scaled declaration's arity before reconstructing the model. Since scaling always adds a Real argument, that older branch attempts to register a zero-arity function interpretation for a nullary original, contrary to `model_core::register_decl(func_decl*, func_interp*)`'s positive-arity assertion. Current Z3 source instead substitutes sigma = 1 first and branches on the original declaration's arity, registering nullary originals as constants. Go follows the corrected current-source behavior; `TestSpacerScaleReconstructsOriginalPredicateModel` exercises the nullary case.

Focused verification: `go test ./pkg/muz/transforms -run 'TestScale|TestRuleName' -count=1 -short` and `go test ./pkg/muz/fp -run 'Test(Spacer|PDR|BMC|CLP|Duality).*Scale|TestScale' -count=1 -short` pass.
